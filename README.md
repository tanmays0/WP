# DV8 Coffee Shop — MLOps Assignment

## 1. Project Overview

**DV8** is a modern eCommerce coffee shop web application built using **HTML, CSS, and JavaScript**. It provides a clean and responsive user interface, interactive product listings, shopping cart functionality, authentication pages, and smooth client-side navigation.

This project demonstrates how an **MLOps lifecycle** can be integrated into a real-world eCommerce application through a proposed **Product Recommendation System**.

The project also follows a structured Git branching strategy using:

- `main`
- `dev`
- `feature/*`

---
